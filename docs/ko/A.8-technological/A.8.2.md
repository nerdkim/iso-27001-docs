# A.8.2 특권 접근 권한 (Privileged access rights)

| 구분 | 내용 |
|---|---|
| 표준 | ISO/IEC 27001:2022 Annex A |

| 통제 | A.8.2 특권 접근 권한 |
| 통제 유형(참고) | 예방적 / 탐지적 (Preventive/Detective) |
| 보안 속성(참고) | 기밀성 / 무결성 / 가용성 |

## 통제 목적

특권 접근 권한(관리자, root, 시스템/DB 관리자 권한 등)은 오남용되거나 탈취될 경우 조직 전반에 광범위한 피해를 초래하므로, 이를 필요한 인원에게 최소한으로 부여하고 사용을 엄격히 통제하는 것을 요구합니다. 특권 계정의 부여, 사용, 검토, 회수 전 과정을 관리하고 일반 업무 계정과 분리하여, 권한 오용 및 침해 위험을 낮추고 특권 활동에 대한 책임추적성을 확보하는 것을 목적으로 합니다.

## 주요 확인사항

1. 특권 접근 권한의 부여 기준과 승인 절차를 정의하고, 최소권한 및 업무상 필요(need-to-use)에 따라 부여하고 있는가?
2. 특권 계정을 일반 사용자 계정과 분리하여 개인별로 식별하고, 공용/기본 관리자 계정의 사용을 통제하고 있는가?
3. 특권 접근에 강화된 인증(다중인증 등)을 적용하고, 세션/사용 시간 제한 또는 임시 부여(just-in-time)를 고려하고 있는가?
4. 특권 계정의 활동을 로그로 기록/보존하고 정기적으로 검토하며, 권한 보유 현황을 주기적으로 재검토하여 불필요한 권한을 회수하는가?
5. 특권 자격증명(관리자 비밀번호, SSH 키 등)을 안전하게 보관/교체하고, 외부자/위탁 인력에게 부여된 특권 권한을 별도로 관리하는가?

## 이행 지침

- 특권 권한의 종류/역할 목록을 정의하고, 부여는 문서화된 승인과 만료(기한)를 전제로 처리하며 상시 보유를 최소화합니다.
- 개인별로 식별 가능한 특권 계정을 사용하고, 공용 관리자 계정 사용을 최소화하되 부득이한 경우 사용 기록과 책임자를 추적할 수 있도록 합니다.
- 특권 접근에는 다중인증, 배스천/점프호스트 경유, 세션 기록, 권한접근관리(PAM) 솔루션 등의 강화 수단을 적용합니다.
- 임시 승격(just-in-time)으로 필요한 시점에만 특권을 부여하고, 작업 종료 후 자동으로 회수합니다.
- 특권 자격증명은 볼트 등에 안전하게 보관하고 주기적으로 교체하며, 시스템 기본 관리자 계정은 비활성화하거나 명칭/비밀번호를 변경합니다.
- 인사이동/퇴직/직무변경 시 특권 권한을 즉시 조정하고, 정기 접근권한 검토(A.5.18)와 연계하여 과다 부여 여부를 점검합니다.
- 특권 작업 로그는 별도로 보존하고 로깅/모니터링(A.8.15, A.8.16)과 연계하여 이상행위를 탐지합니다.

- ISO 27001 본문 연계: 5.3(조직의 역할/책임 및 권한), 6.1(위험 대응), 8.1(운영 계획 및 통제)
- 인접 Annex A: A.5.15(접근통제), A.5.16(식별정보 관리), A.5.17(인증정보), A.5.18(접근권한), A.8.3(정보 접근 제한), A.8.5(보안 인증), A.8.15(로깅), A.8.16(모니터링 활동), A.8.18(특권 유틸리티 프로그램 사용)
- ISMS-P 대응: 2.5.5 특수 계정 및 권한 관리
- 2013 대응: A.9.2.3(특권 접근 권한의 관리)

## 증적자료

- 특권 권한 부여 신청서 및 승인/변경 이력
- 특권 계정 목록 및 보유 현황(계정, 권한 범위, 부여 사유, 만료일)
- 특권 접근 인증 설정(다중인증), PAM/배스천 정책 화면
- 특권 계정 활동 로그 및 정기 검토 기록
- 특권 자격증명 보관/교체 이력 및 기본 계정 비활성화 증적
- 접근권한 정기 검토 결과 및 불필요 권한 회수 기록

## 부적합 사례

- 특권 권한이 승인/부여 근거 없이 사용되고 있거나 만료/회수 절차가 마련되지 않은 경우
- 다수의 관리자가 공용 root/administrator 계정을 공유하여 개인별 행위 추적이 불가능한 경우
- 특권 접근에 다중인증이 적용되지 않아 단순 비밀번호만으로 접근이 가능한 경우
- 특권 계정의 활동 로그가 기록되지 않거나 기록만 하고 검토되지 않는 경우
- 퇴직/직무변경자의 특권 권한이 회수되지 않고 그대로 유지되는 경우
- 시스템 기본 관리자 계정/비밀번호가 초기값 그대로 방치되어 사용되는 경우
